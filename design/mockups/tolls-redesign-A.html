Direction A — what changed and why

Triage is the architecture

  • The six tabs become lanes grouped by the one thing that decides staff effort: confidence. Green lanes need zero eyes, amber needs judgment, red needs data entry.
  • Confidence is real: the backend already computes matchConfidence (85 = auto-confirm line). The bar + number is the .conf component the marketing shot promised.
  • Nothing deleted: All / Auto-matched / Needs review / Unmatched / Dispatch review / Usage only / Ready to post all remain one click away.

One decision per row

  • The row's primary action follows its state: Confirm (suggested), Dispatched (dispatch hold), Post (ready), Review (ambiguous), Assign (unmatched). Reset / Dispute / Waive live in the ⋯ menu — reachable, not shouting.
  • Raw reason string → chips: plate → "Plate match", withinGraceWindow → "Grace window only", multipleCandidates → "2 possible reservations". Full token map in the NOTES file.
  • The evidence drawer (E key) shows the score ledger with the actual points — trust through arithmetic, not adjectives.

Deliberately kept

  • Search, status filter, Review-only, Refresh, Auto-Match All, Confirm All (count), CSV import — plus the export the queue never had.
  • The honest "198 of 201" truncation notice, compressed to one line with a next step.
  • Provider setup / manual import / CSV / import runs move to their own tab: staff open Tolls 8h/day for the queue, not the credentials form. Flat surfaces, 40px rows, 11px floor, tabular numerals.
