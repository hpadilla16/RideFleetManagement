Decisions captured in this mockup

  • Inline edit on the same panel (no modal) — feels like iOS Settings
  • Default is shown as reference text, not auto-filled-and-hidden; the input always holds the effective value
  • "Using platform default" pill flips to "Custom rate" once a tenant override is persisted
  • Errors are inline, range-aware, and gate the Save button
  • OPS role keeps panel visible (so they can look up a number to quote a customer) but disables inputs and removes the action bar
  • Toast slide-up replaces a heavyweight banner — auto-dismisses
