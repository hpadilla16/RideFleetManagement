Innovation · Post-Check-in AI Audit

Every return gets a second look.

After a check-in closes, the audit runs on its own: rules first (mileage, fuel, agent entries — pure arithmetic, instant), then AI vision (checkout photo vs check-in photo, same angle, opt-in per tenant). Anything suspicious lands in this queue — and a flagged photo pair converts into a damage report in one click, evidence pre-attached.

Design exploration only — no application code. The AI never blocks a check-in and never charges anyone: it suggests, a human decides (same posture as citation OCR → review). ES: La IA sugiere; una persona decide. Nunca cobra sola y nunca frena el check-in.

Tier 1 · Ship first
Rules audit — zero AI, zero cost, every tenant

Everything the owner asked about mileage, gas and agent entries is arithmetic on data the check-in already captures:

  • Odometer in < out → impossible entry (catches legacy/manual paths the wizard doesn’t guard)
  • Miles per day outside the tenant’s band → probable digit typo
  • Fuel up sharply with no refuel record → probable mis-entry
  • Fuel drop with no refill fee → fee engine / rate gap
  • Missing photos, missing signature, backdated return vs photo timestamps
On by default. Runs inline-after-close in the same worker family the fee engine already lives in. ES: Se activa para todos — es matemática, no IA.
Tier 2 · Opt-in per tenant
Photo AI — suggestion engine, never a judge

Same credential pattern as citation OCR: the tenant’s own Anthropic key (encrypted at rest), platform key only by explicit opt-in, loud logging, DPA-compatible.

  • 8 angle pairs per check-in → one structured verdict per pair
  • Confidence shown, threshold configurable; below it, nothing is flagged
  • Honest about limits: lighting, angle drift, rain and dirt cause false positives — the UX says so
  • Cost: order of cents per check-in; live spend shown right in the module KPI
Every verdict is reviewable evidence, not a verdict on the customer. Auto-charge is deliberately not designed. ES: La IA propone, el agente dispone.
