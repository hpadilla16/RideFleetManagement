# Training

Employee/admin tutorials, auto-generated by the `training` agent whenever a feature passes the QA gate (SHIP). One PDF per shipped, user-facing change.

- Format: branded PDF (Ride theme), Spanish by default, 1–2 pages, step-by-step with annotated screens.
- Filename: `YYYY-MM-DD_<feature-slug>_<audience>.pdf` (audience = admins | empleados | all).
- See `INDEX.md` for the catalog.

PDFs themselves are kept local to this folder (gitignored) to avoid bloating the repo; share them directly with the team.
