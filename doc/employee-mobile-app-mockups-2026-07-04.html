Ride Fleet — Employee App (iOS + Android) · Mockups v2

App nativa (wrapper Capacitor sobre el frontend existente) para empleados de los tenants — operaciones de piso: pickups/returns del día, checkout/check-in con fotos, scan de vehículo (QR/VIN/placa), inspecciones, maintenance y notificaciones push. Navegación inferior de 5 tabs con el Scan como acción central. Respeta module-access por persona (beta.212) — si a un empleado le falta un módulo, su tab se reemplaza promoviendo un item de "More" (la barra nunca queda con hueco). Tema #8752FE, mismo lenguaje visual del kiosk y del web app.
Specs de build (v2, post-review de Graphic Design): todo elemento interactivo con hit-area ≥ 44×44pt (el visual puede ser menor, el área de toque no); texto funcional mínimo 11px con contraste ≥ 4.5:1; emojis solo en mockup — el build usa icon set real (Lucide/SF Symbols) tintado al morado de marca; el diagrama de daños del build es el vehicleDiagrams.js aprobado (line-art violeta por vehicle type), no el blob ilustrativo de abajo.
